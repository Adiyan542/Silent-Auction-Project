# 🏀 Fantasy Basketball Auction Draft

A single-player fantasy basketball **auction draft simulator** built with **React**, **Vite**, and **Tailwind CSS**.  
The app simulates a full 12-team fantasy draft where the user competes against AI managers with different bidding strategies.

This project was built as a **final project** to demonstrate front-end development, state management, and UI/UX design.

---

## 🚀 Features

- 🧠 **AI Draft Bots**  
  11 computer-controlled managers with different bidding behaviors (aggressive, balanced, value)

- 💰 **Auction Style Draft**  
  Real time countdown timer, sealed bids, budget constraints, and roster limits

- 🏀 **NBA Player Pool**  
  Preloaded list of NBA stars with ratings, positions, and teams

- 📊 **Live Rosters & Budgets**  
  See every manager’s roster and remaining salary update after each auction

- 🏆 **Draft Summary Screen**  
  Final standings ranked by total roster rating

- 🎨 **Modern UI**  
  Styled with Tailwind CSS (dark mode, responsive layout, smooth interactions)

---

## 🛠️ Tech Stack

- **React** – component-based UI and state management
- **Vite** – fast development build tool
- **Tailwind CSS (v4)** – utility-first styling
- **Lucide React** – icon library
- **JavaScript (ES6+)**


## 🎮 How to Use the App

1. Enter your manager name
2. Create a room with AI managers
3. Start the draft
4. Nominate players when it’s your turn
5. Place bids during auctions
6. Manage your budget and roster
7. View final standings at the end

---

## 🧠 AI Bidding Logic (Overview)

Each AI manager:
- Has a fixed budget and roster size
- Uses a strategy (aggressive, balanced, value)
- Adjusts bids based on player rating and remaining roster spots
- Cannot bid more than allowed by salary constraints
